## 当前定位检查

2026-08-15，中文与英文包均验证了下列边界：建立 Memory、启动或整理项目、明确结构审查、多个项目比较、显式 check-in 和明确的选择困难可以触发对应能力；已知项目续接、普通写作、方向判断和单项目下一步不触发插件。

新项目的项目文件与 Workspace Memory 分开确认。`launch-project` 只生成路由候选；`bootstrap-workspace` 检查别名与路径冲突，展示精确写入，并在获得第二次确认后登记。路径续接测试不依赖名称自动发现。
