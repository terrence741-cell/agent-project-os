## 当前定位检查

2026-08-15，中文与英文包均验证了下列边界：建立 Memory、启动或整理项目、明确结构审查、多个项目比较、显式状态交接和明确的选择困难可以触发对应能力；已知项目续接、普通写作、方向判断和单项目下一步不触发插件。

新项目的项目文件与 Workspace Memory 分开确认。`launch-project` 只生成路由候选；`bootstrap-workspace` 检查别名与路径冲突，展示精确写入，并在获得第二次确认后登记。路径续接测试不依赖名称自动发现。

V1.0.2 新增标准共享 Memory preset：全新用户可获得单一物理库、薄 `MEMORY.md`、按需主题文件、Codex / Claude Code 双宿主入口和本地 Git 恢复提案。精确单文件目标保持更高优先级，未经读取授权的写入目标不得被探测。

2026-08-16，本地真实 Codex CLI 与 Claude Code CLI 在隔离新会话中均自动加载全局薄规则，只读取请求相关主题、项目稳定入口和当前状态；插件未加载时链路仍成立。宿主对工作区外物理路径的访问权限只有在真实失败后才按宿主、操作和精确路径另行提案。
