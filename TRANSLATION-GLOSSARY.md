# Translation glossary

Chinese is the product's primary language. These terms stay in English in both
packages unless a sentence requires a natural Chinese gloss.

| Term | Chinese writing | Rule |
| --- | --- | --- |
| Agent | Agent | Do not replace with a generic assistant. |
| Skill | Skill | Keep the capitalized product term. |
| Memory | Memory | Keep when referring to durable workspace memory. |
| Project | Project | Keep when referring to the model layer. |
| Portfolio | Portfolio | Keep when referring to the cross-project layer. |
| Markdown | Markdown | Keep. |
| check-in | check-in | Keep; explain once in natural Chinese when useful. |
| fixture | fixture | Keep in test-facing text. |

Never translate or rename Skill identifiers, manifest keys, paths, state labels,
or confirmation boundaries. Translate natural-language triggers, headings,
examples, and user-facing prompts for the package's intended reader.
