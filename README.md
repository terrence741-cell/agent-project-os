# Agent Project OS

Agent Project OS helps a file-system Agent safely resume real Markdown projects
across sessions. This repository ships two complete language packages with the
same six Skills.

| Your working language | Install exactly this package |
| --- | --- |
| 中文 | `agent-project-os` |
| English | `agent-project-os-en` |

Do **not** install both: they deliberately expose the same Skill names.

## Install the English package

After adding this repository's Marketplace, install `agent-project-os-en` only.
If you ask an Agent to do this for you, use: “Install the English Agent Project
OS package only: `agent-project-os-en`.”

Read the complete English rules and package documentation in
[`plugins/agent-project-os-en/`](plugins/agent-project-os-en/). For Chinese,
see [README.zh-CN.md](README.zh-CN.md).

The repository is under V1.0.0 review. See the
[bilingual distribution contract](distribution/BILINGUAL-DISTRIBUTION.md) and
[translation glossary](TRANSLATION-GLOSSARY.md).
