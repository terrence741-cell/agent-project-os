# Agent Project OS

Agent Project OS 帮助文件系统型 Agent 在跨会话时安全续接真实 Markdown
项目。本仓库提供两套行为等价、可独立安装的语言包。

| 你的工作语言 | 只安装这一包 |
| --- | --- |
| 中文 | `agent-project-os` |
| English | `agent-project-os-en` |

**不要同时安装两包。** 它们有意提供相同的 Skill 名。

## 安装中文包

添加本仓库的 Marketplace 后，只安装 `agent-project-os`。如果让 Agent
代为安装，请说：“安装中文 Agent Project OS：`agent-project-os`，不要安装英文包。”

完整中文规则与包内文档位于
[`plugins/agent-project-os/`](plugins/agent-project-os/)。英文读者请看
[README.md](README.md)。

本仓库目前处于 V1.0.0 审核阶段。双语发布规则见
[distribution/BILINGUAL-DISTRIBUTION.md](distribution/BILINGUAL-DISTRIBUTION.md)，
固定术语见 [TRANSLATION-GLOSSARY.md](TRANSLATION-GLOSSARY.md)。
